# Learning Cards App

A standalone Module 3 Android app demonstrating a collection-backed `LazyColumn`, reusable Material 3 cards, animation, accessibility semantics, and light/dark themes.

## Run

Open this folder in Android Studio, allow Gradle sync to finish, select a USB-debugging-enabled device, and run the `app` configuration.

## Verify

```powershell
.\gradlew.bat testDebugUnitTest
.\gradlew.bat assembleDebug assembleDebugAndroidTest
```
