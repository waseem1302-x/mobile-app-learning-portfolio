# Source code

[`LearningCardsApp`](LearningCardsApp/) is the runnable Unit 3 implementation. Open that directory as an Android Studio project.

The app demonstrates collection-backed UI, `LazyColumn`, stable item identity, reusable Material cards, animation, dark-mode theming, accessibility semantics, and automated tests.

```powershell
cd LearningCardsApp
.\gradlew.bat testDebugUnitTest
.\gradlew.bat assembleDebug assembleDebugAndroidTest
```
