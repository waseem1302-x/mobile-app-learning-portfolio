# Source code

[`ComposeInteractionLab`](ComposeInteractionLab/) is the runnable Unit 2 implementation. Open that directory as an Android Studio project.

It contains a stateful dice roller, an input-driven tip calculator, Material 3 light/dark theming, local calculation tests, and a Compose UI test. Build it with:

```powershell
cd ComposeInteractionLab
.\gradlew.bat testDebugUnitTest
.\gradlew.bat assembleDebug assembleDebugAndroidTest
```
