# Source code

[`CourseNavigatorApp`](CourseNavigatorApp/) is the runnable Unit 4 implementation. Open that directory as an Android Studio project.

The app demonstrates ViewModel-owned `StateFlow`, Navigation Compose destinations and arguments, compact navigation, an expanded list-detail layout, and automated tests.

```powershell
cd CourseNavigatorApp
.\gradlew.bat testDebugUnitTest
.\gradlew.bat assembleDebug assembleDebugAndroidTest
```
